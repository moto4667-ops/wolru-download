# 먼작귀 월루계산기

먼작귀 친구들이 바탕화면을 돌아다니면서, 오늘 지금까지 번 돈과 퇴근까지 남은 시간을 머리 위에 달고 다녀요.
월루(몰래 노는) 시간은 돈으로 따로 계산해 주고, 퇴근하면 영수증을 끊어 줘요.

**받기:** [Releases](../../releases/latest)에서 내 컴퓨터에 맞는 파일을 받으세요.

| 컴퓨터 | 파일 |
|---|---|
| Windows 10/11 | `wolru-setup.exe` |
| Mac (Apple 실리콘·인텔) | `wolru-mac.dmg` |

## 설치할 때
- **Windows**: 서명하지 않은 개인 제작 프로그램이라 "Windows의 PC 보호" 창이 뜰 수 있어요. **추가 정보 → 실행**을 누르면 설치돼요. 관리자 권한 없이 내 계정에만 설치돼요.
- **Mac**: dmg를 열고 앱을 응용 프로그램 폴더로 끌어다 놓으세요. "확인되지 않은 개발자" 창이 뜨면 **시스템 설정 → 개인정보 보호 및 보안 → 그래도 열기**를 누르세요.

## 기록은
이 컴퓨터 안에만 저장되고 어디로도 보내지 않아요. 앱을 지워도 기록은 남아요. 설정 → 백업으로 옮길 수 있어요.
새 버전이 나왔는지 알려 주려고 관리 창을 열 때 버전 번호 파일 하나만 읽어 와요.

## 알려 둘 것
입력한 급여로 대충 계산한 재미용 숫자예요. 실제 급여·수당 계산이 아니에요.

## 팬 제작물 고지
원작과 무관한 비공식 팬 제작물입니다. 캐릭터의 권리는 원작자에게 있습니다.
무료·비영리로만 배포하며, 권리자의 요청이 있으면 즉시 배포를 중지합니다.
